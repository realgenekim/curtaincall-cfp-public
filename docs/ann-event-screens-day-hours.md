# Notes for Ann — what changed on the event screens today

*August 11, 2026. Five small things, all on the screens you use every day. Nothing you
have already set up needs to be redone.*

## 1. You can now say when the programming day starts and ends

On the event details page there are two new time fields: **Programming day starts** and
**Programming day ends**. They tell the public program page what a conference day looks
like — the page prints "Programming 9am – 5pm" at the top of the agenda, so someone
reading it knows to be in the room at nine even before every session is placed.

If you never touch them, they are **9:00 to 17:00**. Change them for an event that runs
8am to 6pm, and the program page says so immediately.

## 2. The public program is one page now

Everything an attendee wants — the featured speakers and the agenda — is on a single
stacked page at **/program/your-event**. Scroll, don't hunt through tabs.

The old separate agenda, speakers, and sessions addresses still work: anyone who clicks
one is carried to the new page automatically. **Links you have already sent in emails,
newsletters, or the website will not break.**

## 3. An empty day now says something instead of disappearing

Before, a day with nothing scheduled on it simply vanished from the agenda, which made a
half-built schedule look broken. Now it says:

> Sessions coming — the call for speakers is open.

And if nothing at all is scheduled yet, the page says the agenda will be published soon.
This means you can publish the schedule the moment the first sessions are locked in
without waiting for the whole grid to be full. A partly-published program now reads as
*in progress*, which is what it is.

## 4. Attendees can add the dates to their calendar before there is an agenda

The calendar subscription now always includes a **hold-the-date entry for the event
itself** — the name, the dates, and the location, marked as all-day. Somebody can
subscribe the day the call for speakers opens, get the dates on their calendar right
away, and then watch the sessions appear in that same subscription as we publish them.
They never have to come back and re-add anything.

The link lives at the bottom of the program page ("Subscribe by calendar"), and on an
event with no agenda yet it is offered up top as **"Hold the dates →"**. It is a normal
calendar link — feel free to put it in emails.

If the event dates ever move, the entry already on someone's calendar quietly updates.
It does not turn into a second entry.

## 5. Featured speakers are one list, edited in one place

The speakers shown on the call-for-speakers page and the speakers shown on the program
page are now **the same list** — the announced speakers. Add someone once and they show
up on both. Remove someone once and they come off both. There is no second list to keep
in sync anymore, and no more "she's still on the CFP page" surprises.

---

**If something looks off**, the two most likely culprits: the programming hours on the
event details page (they drive that "Programming 9am – 5pm" line), and whether a speaker
is on the announced list (that drives both public pages). Everything else on those
screens works the way it did yesterday.
