All the comments, in the table

Your fulcro app put every comment in the table and it worked. Three ways to do it here — each shows the same row: 2 ratings + 2 comments. All show FULL text, no truncation.

T1 — stacked mini-bubbles (recommended)

The detail page's thread, miniaturized: avatar + balloon per comment, stacked under the title. Loudest "this is a conversation" signal; costs the most height on heavily-discussed rows — which is exactly when you WANT the height.
